# TP1 - Introducción a Node.js

## Descripción

Esta es el primer trabajo practico a realizar para la cursada de NodeJS - UTN.

Objetivos:

- Instalar y configurar Node.js.
- Comprender la ejecución de código JavaScript fuera del navegador y aplicar el uso básico de módulos nativos.

## Instalación

Chequeo de version de Node y npm, instalacion de las dependencias del proyecto.

```
node -v
npm -v
npm i
```

## Uso

Ejecutamos la aplicacion y podemos observar por consola los mensajes requeridos.

```
npm run dev
```
